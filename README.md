# BackendMaria

Servicio backend del proyecto **TiendaMariaMejorada**, desarrollado con propósitos educativos.

## Integraciones y Dependencias

* **Base de Datos / Cloud:** Vinculado al proyecto en Firebase **MariaArticulos** (Cloud Firestore).
* **Frontend:** Provee la API REST consumida por la aplicación cliente **TiendaMariaMejoradaFront** (repositorio `FrontMaria`).

---

## Requisitos Previos

* [Node.js](https://nodejs.org/) (versión LTS recomendada)
* Cuenta de Firebase con acceso al proyecto **MariaArticulos**
